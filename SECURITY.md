# Security policy

This is a hobbyist, unofficial, self-hosted application designed for a trusted private network. No built-in user authentication is provided. Never expose port 5000 publicly without an authenticated reverse proxy and access controls.

**Report vulnerabilities privately:** use GitHub's private vulnerability reporting feature if enabled by the repository owner; otherwise contact the maintainer via a private channel rather than a public issue. Do not post access tokens, logs containing identifiers, mower serials, GPS coordinates, Wi-Fi identifiers, maps or screenshots of private property.

Rotate any credential accidentally exposed and remove it from history; deleting the current file alone is not sufficient. Review account permissions and external integrations before enabling movement controls.
